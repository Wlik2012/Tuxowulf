# Tuxowulf
Tuxowulf is an old text about Tux mythology.

**Also known as Tuxowolf** — this spelling is used by some later sources, including Wikipedia. The preserved 1999 source itself uses **Tuxowulf**.

I've found a nearly lost work in the archives: Tuxowulf (https://web.archive.org/web/19991013063352/http://davix.latesky.net/apoc/booke/tuxowulf.html). I'm copying it to this repository so it can survive for another 25+ years. I'd love to credit the author and their license, but I don't know them. Enjoy reading.
